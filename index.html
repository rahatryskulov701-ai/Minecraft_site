🎮 Minecraft Commands

Добро пожаловать в Minecraft Command Center! Здесь собраны полезные команды Minecraft Java Edition: телепортация, предметы, эффекты, мобы, погода, время, игровые правила и многое другое.

🔎 Поиск команд

🔍

💎 Дать алмазы

Выдаёт игроку 64 алмаза.

/give @p minecraft:diamond 64

🍖 Дать еду

Выдаёт игроку 64 жареной говядины.

/give @p minecraft:cooked_beef 64

📍 Телепортация

Телепортирует игрока к координатам.

/tp @p 100 70 100

🟩 Креатив

Переключает игрока в творческий режим.

/gamemode creative

⚔️ Выживание

Переключает игрока в режим выживания.

/gamemode survival

🗺️ Приключение

Переключает игрока в приключенческий режим.

/gamemode adventure

👁️ Наблюдатель

Включает режим наблюдателя.

/gamemode spectator

💀 Убить игрока

Мгновенно убивает выбранную цель.

/kill @p

❤️ Вылечить

Даёт игроку эффект мгновенного лечения.

/effect give @p minecraft:instant_health 1 255 true

⚡ Скорость

Даёт игроку повышенную скорость.

/effect give @p minecraft:speed 60 2 true

💪 Сила

Даёт игроку эффект силы.

/effect give @p minecraft:strength 60 2 true

🦘 Прыгучесть

Увеличивает высоту прыжка.

/effect give @p minecraft:jump_boost 60 2 true

☀️ День

Устанавливает дневное время.

/time set day

🌙 Ночь

Устанавливает ночное время.

/time set night

☀️ Ясная погода

Останавливает дождь и грозу.

/weather clear

🌧️ Дождь

Включает дождливую погоду.

/weather rain

⛈️ Гроза

Включает грозу.

/weather thunder

🏠 Найти деревню

Показывает координаты ближайшей деревни.

/locate structure minecraft:village_plains

🔥 Найти крепость

Ищет ближайшую крепость в Нижнем мире.

/locate structure minecraft:fortress

🏰 Найти город Энда

Ищет ближайший город Энда.

/locate structure minecraft:end_city

💥 Призвать крипера

Создаёт крипера рядом с игроком.

/summon minecraft:creeper ~ ~ ~

🧟 Призвать зомби

Создаёт зомби рядом с игроком.

/summon minecraft:zombie ~ ~ ~

💀 Призвать скелета

Создаёт скелета рядом с игроком.

/summon minecraft:skeleton ~ ~ ~

🗿 Железный голем

Призывает железного голема.

/summon minecraft:iron_golem ~ ~ ~

🎒 Сохранение инвентаря

Предметы не выпадают после смерти.

/gamerule keepInventory true

🛡️ Запретить разрушение мобами

Запрещает мобам изменять блоки мира.

/gamerule mobGriefing false

⏸️ Остановить время

Останавливает смену дня и ночи.

/gamerule doDaylightCycle false

▶️ Запустить время

Возвращает обычную смену дня и ночи.

/gamerule doDaylightCycle true

🕊️ Мирная сложность

Устанавливает мирную сложность.

/difficulty peaceful

🙂 Лёгкая сложность

Устанавливает лёгкую сложность.

/difficulty easy

💀 Сложная сложность

Устанавливает сложную сложность.

/difficulty hard

📖 Как использовать команды Minecraft?

Открой чат Minecraft Java Edition клавишей T, вставь нужную команду и нажми Enter. Для большинства команд нужны включённые читы или соответствующие права на сервере.
